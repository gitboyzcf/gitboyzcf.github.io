# Easy-Vibe 零基础入门06：接入 AI 能力

> 本文整理自 [Datawhale Easy-Vibe 教程](https://datawhalechina.github.io/easy-vibe/zh-cn/stage-1/integrating-ai-capabilities/)，系列连载第 6 篇。

## 一、本章导读

🎯 **学习目标**：API、文本模型、文生图、原型集成

前面的原型还只是一个"壳子"——点击按钮不会真的生成内容。这一章要让原型"活"起来：接入真实的 AI 能力。

⏱️ **预计耗时**：约 1 天
📦 **预期产出**：原型接入 1 个文本模型 + 1 个图像模型（可选）

---

## 二、API 基础概念

API 可以简单理解为：你按对方要求的格式"发一个问题"，对方就按同样的格式"回一个结果"。

**核心要素**：
- **API Key**（通行证）
- **Endpoint**（接口路径）
- **调用/请求**、**请求内容**、**响应结果**、**错误处理**

🔐 **安全注意事项**：
- 绝对不要分享到群聊或发布在公开论坛
- 不要硬编码到代码中并提交到 Git 仓库
- 如怀疑 Key 已泄露，立即更换新 Key

---

## 三、接入文本生成 API：DeepSeek

跟着 3 步走：
1. 在 DeepSeek 平台创建一个 API Key
2. 在 DeepSeek 文档中找到文本生成示例
3. 打开 AI IDE 把 API Key + 官方示例粘贴进去

---

## 四、接入图像生成 API：Seedream 即梦

接入图片生成的功能，支持从文字描述生成图片，或者对图片进行修改。

**更多图像服务选型**：
- Recraft 集成（偏设计生产）
- Qwen Image / Qwen Image Edit 集成

---

## 五、如何找到"当前更强"的 AI 模型？

- **LMArena**（lmarena.ai）：判断"多数人更偏好哪个模型的回答"
- **Artificial Analysis**（artificialanalysis.ai）：把"效果/价格/速度"放在同一张表里对比
