# Hermes Agent 桌面版完全指南：从安装到配置，手把手教你拥有你的第一个"数字员工"


## 🤔 她是什么？为什么值得你了解？

### 一句话解释

**Hermes Agent** = 一个**住在你电脑里的数字员工**。

她可以：
- 💬 跟你聊天，回答问题
- 📁 操作你的文件、代码、浏览器
- 🌐 帮你上网查资料、操作网页
- ⏰ 定时执行任务（比如每天早上发日报）
- 📱 接入微信，随时远程操控你的电脑

而且最酷的是——**她会学习、会记住你是谁、会越用越聪明**。

### 与普通 AI 的区别

| 对比项 | 普通 ChatGPT | Hermes Agent 桌面版 |
|--------|-------------|-------------------|
| 运行位置 | 网页/APP | 你的电脑桌面 |
| 能操作文件 | ❌ | ✅ 直接读写你硬盘的数据 |
| 能上网执行 | ❌ | ✅ 打开浏览器、点击、填表 |
| 记忆 | 每次聊完就忘 | ✅ 跨对话记忆 |
| 定时任务 | ❌ | ✅ 自动执行 |
| 微信对接 | ❌ | ✅ 通过微信远程操控 |
| 无需代码 | ❌（高级功能需要） | ✅ 全部 GUI 操作 |

### 适合谁？

- 🧑‍💻 **开发者**：写代码、改 bug、跑测试，一句话搞定
- 📊 **运营/产品**：做数据分析、写文档、查资料，省掉重复劳动
- 🏠 **普通用户**：自动整理文件、定时发报告、微信远程操控电脑
- 🤖 **AI 爱好者**：想体验最新 AI Agent 技术的玩家

> 💡 **简单说**：只要你有 Windows 电脑，并且想让 AI 帮你干活——她就适合你。

## 一、安装前的准备

### 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 操作系统 | Windows 10（64位） | Windows 11 |
| 内存 | 4GB | 8GB+ |
| 磁盘空间 | 2GB 可用 | 5GB+（考虑模型缓存） |
| 网络 | 能访问 GitHub | 稳定网络 |

**额外说明**：
- 不需要安装 Python、Node.js 等编程环境
- 桌面版自带运行环境，**开箱即用**
- 如果你的电脑能流畅运行微信、浏览器，就能跑她

### 安装账号/软件准备

在开始之前，你需要确认已有以下东西：

| 需要准备 | 说明 | 没有怎么办 |
|---------|------|-----------|
| **模型 API Key** | 需要配置一个 AI 模型 | 可以去 OpenAI、DeepSeek、Kimi、阿里云百炼等申请 |
| **微软账号**（可选） | 部分功能可能需要 | 没有也能用 |
| **微信**（可选） | 如果要用微信远程操控 | 不是必须的，可以先跳过 |

> 💡 **新手提示**：如果你不确定用哪个模型，**先用 Kimi（月之暗面）或 DeepSeek**，性价比高、中文好、申请简单。

## 三、初始配置：你的第一个"数字员工"

###  选择你的供应商
![[../../../assets/images/2026/Pasted image 20260710183136.png]]
Nous Portal 是官方内置提供的，几乎包含所有模型类似于一个中转站，不过需要登录订阅才能使用（有需要可以直接选择）

这里我选择右下角I have an API key  我自己有模型的key ，想用什么模型去百度搜对应的官网即可



#### 选择对应供应商输入 API Key

你需要在模型供应商那里获取一个 **API Key**。

**以 Kimi 为例**：
1. 访问 [platform.moonshot.cn](https://platform.moonshot.cn)
2. 注册账号 → 登录 → 左侧菜单「API 管理」
3. 点击「创建新的 API Key」
4. 复制生成的 Key（以 `sk-` 开头）


**粘贴到 Hermes 配置中**：
1. 回到 Hermes 桌面版
2. 在 API Key 输入框中粘贴你复制的 Key
3. 点击"connect"

![[../../../assets/images/2026/Pasted image 20260710185845.png]]


#### 然后选择具体模型

同一个供应商下可能有多个模型，例如 Kimi 常用有：
- `kimi 2.5`
- `kimi 2.6`

📷 【截图位置：模型版本选择界面】

> 💡 **新手推荐**：先选**性价比最高的模型**，比如 DeepSeek-V4或 Kimi 的 2.6 版本。等熟练后再换更强的。

## 五、核心功能详解

### 对话能力：不只是聊天

#### 基础对话
就像你在微信里发消息一样，在输入框输入内容，然后按回车：

```
帮我写一段朋友圈文案，主题是周末去露营，风格轻松幽默
```

#### 多轮对话
Hermes 会记住**你们这一轮对话的上下文**：

```
你：帮我写一段朋友圈文案
她：好的，你想写什么主题？
你：周末露营
她：明白了，我帮你写一段……
```

> ⚠️ **注意**：这种"记忆"是短期的，重启软件或开始新对话后会重置。长期记忆需要另外配置。

#### 文件对话
你可以直接**拖拽文件**到对话窗口


Hermes 会自动识别文件类型：
- **代码文件**（.js, .py, .vue……）：能读、能改、能解释
- **文档文件**（.pdf, .docx, .txt……）：能读、能总结、能问答
- **图片**（需要模型支持多模态）：能看图说话

### 文件操作：让 AI 帮你整理电脑

你能让 Hermes 帮你做的事情：

| 你说的话 | 她会做的事 |
|---------|-----------|
| "帮我找到 D 盘里所有的 PDF 文件" | 遍历目录，列出所有 PDF |
| "把下载文件夹里的文件按日期整理" | 创建日期文件夹，移动文件 |
| "把这份 Word 转成 PDF" | 调用工具转换格式 |
| "这个代码有 bug，帮我看看" | 分析代码，指出问题 |
| "帮我写一个 Python 脚本处理 Excel" | 写代码并执行 |


###  浏览器操作：让她替你上网

这是非常强大的功能——Hermes 可以**控制浏览器**：

```
帮我打开百度，搜索"今天北京天气"，把结果告诉我
```

她会：
1. 打开浏览器
2. 导航到 baidu.com
3. 在搜索框输入关键词
4. 点击搜索按钮
5. 读取结果
6. 整理后回复你


### 定时任务：设置一次，自动执行

点击 **左下角排程** 或 **直接聊天框发送** 功能：


你可以设置：
- **定时执行任务**：每天/每周/每月自动执行某个操作
- **间隔执行**：每隔 N 分钟/小时执行一次
- **触发条件**：满足某个条件时执行

**示例场景**：

| 场景 | 配置方式 |
|------|---------|
| "每天早上 9 点发日报到微信群" | 定时任务，每天 9:00 |
| "每隔 30 分钟检查一次服务器状态" | 间隔任务，30 分钟 |
| "监控某个网页，有变化通知我" | 条件任务，网页变化时 |

### 技能系统：给 AI 装"插件"

Hermes 有一个**技能（Skills）系统**，可以扩展她的能力。

在技能管理界面，你可以看到已安装的技能：


| 技能名称 | 功能 |
|---------|------|
| `web` | 搜索、浏览网页 |
| `file` | 文件读写、目录操作 |
| `terminal` | 执行命令行 |
| `browser` | 浏览器控制 |
| `memory` | 记忆管理 |

## 六、进阶配置

### 多个模型切换

你可以配置**多个模型**，需要时切换：

![[../../../assets/images/2026/Pasted image 20260713101848.png]]

**切换方式**：
1. 在对话界面，点击左上角模型名称
2. 从下拉菜单选择另一个模型
3. 后续消息就会用新模型来回复

> 💡 **实用技巧**：日常用便宜模型（如 DeepSeek、kimi），复杂任务换强模型（如 Claude 或 ChatGPT）。

### 网关配置

点击 **设置 → 网关**：

你可以配置：
- **网关端口**：默认即可
- **白名单**：哪些用户可以给 AI 发消息
- **消息平台**：启用/禁用微信、Telegram 等
- **日志级别**：调试用，一般保持默认

###  工作空间设置

Hermes 会创建一个**工作目录**，存放：
- 配置文件（`.env`）
- 日志文件
- 技能脚本
- 缓存数据


**修改工作空间位置**：
1. 文件默认在 `C:\Users\<用户名>\.hermes\`
2. 如果 C 盘紧张，可以迁移到其他盘符
3. 通过"设置 → 高级 → 数据目录"修改

### 安全与权限

这是**非常重要**的部分——AI 有操作你电脑的能力，安全必须考虑。

**推荐设置**：

| 设置项 | 推荐值 | 原因 |
|--------|--------|------|
| 文件访问权限 | 限制目录 | 避免 AI 误删系统文件 |
| 命令执行 | 需确认 | 高危操作问你一声 |
| 网络访问 | 启用 | 否则没法搜网页 |
| 白名单 | 启用 | 只允许你的微信号 |
| 自动更新 | 启用 | 修复安全漏洞 |

## 七、常见问题排查

### 安装问题

**Q：安装时提示"无法连接到服务器"**

```
检查你的网络是否正常
尝试关闭 VPN / 代理
换用手机热点重新下载
```

**Q：安装后打不开**

```
以管理员身份运行
检查 Windows 版本是否太旧（需 Win 10 64位以上）
尝试卸载后重新安装
```

### 连接问题

**Q：模型一直连接失败**

```
① 检查 API Key 是否复制完整（前后不要有空格）
② 检查该 Key 是否已过期
③ 尝试在浏览器中 ping api 地址，看是否通
④ 检查本地网络是否可以访问外网
```

**Q：微信扫码后没有反应**

```
① 确认是"文件传输助手"类型的 AI 助手（不是普通好友）
② 尝试发送 /restart 命令
③ 关闭 Hermes 后重新打开微信通道
```

### 使用问题

**Q：AI 回复很慢**

```
① 检查你的网络延迟
② 尝试换更快的模型（如 DeepSeek-V3）
③ 检查是否开启了太多技能（skills）
```

**Q：AI 说"我做不了这个"**

```
① 该功能可能需要安装对应的技能（skills）
② 模型能力有限，换更强的模型
③ 或该操作被安全设置拦截了
```

**Q：如何重置配置？**

```
方法一：设置 → 恢复默认设置
方法二：关闭软件 → 删除 .hermes 文件夹 → 重新启动
（⚠️ 注意：方法二会清除所有配置！）
```
